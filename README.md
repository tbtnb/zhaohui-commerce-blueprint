# 昭回 · 电商自治蓝图

研究基线：2026-09-14。独立静态研究站点，不是商家生产管理系统。

范围：国内与跨境电商接入、运营流程、数据监听与汇总、受控自动接入、系统监控；不接入财务、支付、结算或退款执行。

公开发布内容只包含本次撰写的研究摘要、公开来源链接、模块路径级架构分析以及合成演示，不包含原项目源码、客户数据、账号信息或凭据。原项目的未提交修改不属于此站点。

网页中的能力合同和路线均为设计建议，除明确标注的本次源码检查与历史验收记录外，不代表已有生产功能。本次没有执行真实店铺写操作，也没有重新执行历史 Agent 业务验收。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8767/`。页面为原生 HTML/CSS/JavaScript，无前端构建依赖、无外部字体或追踪脚本。

## 发布

将本目录的静态文件发布到独立公开仓库，GitHub Pages 使用 `main` 分支根目录。不要将 `online-agent` 原仓库整体推送到公开仓库。Pages 仅承载报告，不承载 Webhook、数据库、后台任务或密钥。

## 验证

`qa.mjs` 是 Playwright 浏览器行为检查脚本。设置 `PLAYWRIGHT_MODULE` 为本机 Playwright 包入口，`SITE_URL` 为测试地址后运行。覆盖移动端/桌面溢出、平台筛选、场景切换、异常演示、来源检索与浏览器错误；验证结果只证明报告站点，不证明电商平台接入。

## 重建与浏览器检查

```sh
python3 build.py
PLAYWRIGHT_MODULE=/path/to/playwright/index.js node qa.mjs
```

省略 SITE_URL 时，检查脚本会临时启动仅监听本机的随机端口服务器，并在结束后关闭。设置 SITE_URL 可验证已发布页面。QA 输出写入被忽略的 qa-output/ 目录。

公开发布仓库与原项目 Git 仓库隔离；仅复制本目录的明确文件清单。
