# 昭回 · 一家公司的 AI 之旅

当前首页是暖白纸艺风格的互动演示：从老板的一个想法开始，认识公司、自动接入各类系统、形成安排、分三步搭建，再观看 AI 如何接续经营变化。

## 本版内容

- 接入环节自动演示六组系统依次连接，不再要求选择系统、资料方式或核对商品。
- 全流程使用生图制作的纸艺角色、公司、立体书、商品和经营物件；参考图与生成图稿保存在 `paper/reference/`。
- 三个连续经营故事：供货延期、发现新品机会、顾客反馈改进。
- 每个故事含自动处理、资料不足、操作失败、人工介入四种走向，共十二个分支。
- 六段演示：事件触发 → 读取事实 → 作出判断 → 跨系统处理 → 核验结果 → 继续经营。
- 支持播放、暂停、章节跳转、逐步查看、重播、调速、减少动效，以及经营记录导出。
- 资料不足时等待补齐；操作失败时保留已经完成的回执；人工暂停不会抹掉已完成工作。

## 本地预览

```sh
python3 build-company.py
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。研究资料位于 `/company/research.html`，也已应用纸艺配色。

```sh
node --test paper/story.test.mjs
```

## 当前实现

- `paper/index.html`：首页源模板，由构建器复制到根目录。
- `paper/app.mjs`：提问、搭建、播放器与结果页。
- `paper/story.mjs`：故事、异常分支、动作结果和记录导出。
- `paper/style.css`：纸艺构图、图层动画和响应式布局。
- `paper/assets/`：独立生成的纸艺图层。
- `design-qa.md`：视觉对照与浏览器验证记录。

## 研究与运行边界

此前的八模板研究保留在 `company/research/report.md`，来源及访问限制记录在 `company/research/sources.json`；它们是设计背景，不代表本版已经实现八套业务动画。知乎正文受登录或安全验证限制，派代访问失败，没有将其记为已读全文。

本网站使用合成资料与模拟回执，不连接真实公司账号，不发送消息或投放广告。平台信息依据职责推导；真实接入与执行仍须验证。`online-agent` 仅作只读参考。财务与税务不在演示范围。
