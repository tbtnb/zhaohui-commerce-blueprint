# 昭回 · 从一个想法开始搭建

本目录是独立互动说明页，路径为 `/experience/`。保留同一仓库已有的首页、场景手册与技术附录，不要求原应用具有与演示完全相同的可视化界面。

用户可以从 60 句含糊的经营想法开始，回答具体问题，在对话中选择已有连接、新建连接或工作资料，再确认范围、开始方式与结果。每项均提供实际平台搭建说明、运行演示、问题处理、重复输入与反馈修改。

## 演示的内容

60 项使用各自的业务对象、前后变化、问题和改进建议。采用 23 类空间布局，配合 60 套业务动作说明、图形和移动方式；基础图形与播放控制共用，并非制作了 60 个完全独立的视频播放器。

接入是搭建步骤的一部分。已有接入能力可以被复用，需要登录或选择允许范围时由用户确认。正式使用还必须核对真实读取结果。当前通用连接器只读、文件检查仅观察指定工作文件，这些限制没有因为画出动画而改变。

本页是预设问答与合成数据演示，没有实时模型服务、真实账号登录、店铺操作、后台任务或资金动作。补充文字只进入说明，不能由本页理解并执行任意新需求。导出文件是需求说明，不是已激活的运行配置。

## 本地构建

```sh
python3 build.py
node export-handbook.mjs
```

只读取和修改本目录，不覆盖仓库主首页。`journeys.json` 保存当前场景脚本，`journey-template.html` 为页面模板，`journey.mjs` 管理问答与演示状态。`journey-art.mjs` 和 `journey-visuals.mjs` 对应业务插图、运动路线与说明。

从仓库根目录开启静态服务后访问 `/experience/`，可以同时检查返回手册与附录的链接。

## 浏览器检查

安装并指定 Playwright 后：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.js node qa.mjs
```

脚本自动启动仅监听本机的临时服务并在结束时关闭。传入 `SITE_URL` 可检查发布后的 `/experience/` 页面。结果保存在忽略目录 `qa-output/`。

检查范围包括 60 次正常运行、60 次资料异常处理、60 次重复输入，以及 3 类资料方式与 3 类触发的 9 种组合。另检查实际导出内容、范围选择、简明/详细结果、暂停、单步、重播、反馈修改、移动端、无脚本阅读、旧链接和网络请求。

这些结果只证明说明网站的行为，不证明真实商家的自动化已经接通或完成验收。
